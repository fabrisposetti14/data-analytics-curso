# RetailPro — Proyecto de Análisis de Datos

Este repositorio contiene los entregables y scripts desarrollados durante el curso de Data Analytics de CoderHouse para el proyecto **RetailPro** (TechStore).

## 🛠️ Herramientas Utilizadas
- **SQL Server / SSMS:** Creación de bases de datos, consultas de agregación, JOINs y vistas.
- **Power BI Desktop:** Modelado de datos, medidas DAX y tableros interactivos.
- **IA (Claude / Copilot):** Copiloto técnico para documentación y optimización de código.

## 📁 Estructura del Repositorio
- `módulo 3/`: Scripts SQL de creación de la base `Ventas_Tech_DB` e inserción de datos.
- `módulo 4/`: Consultas de negocio (resumen ejecutivo mensual y ranking de productos).
- `módulo 5/`: Consultas avanzadas con INNER JOINs y vistas relacionales.
- `módulo-8/`: Archivos de configuración y entregables de Power BI.
- `Sposetti_Fabricio_Checkpoint2.pbix`: Archivo principal de Power BI con el informe y modelo de datos.

## 🚀 Cómo Ejecutar los Scripts
1. Abrir **SQL Server Management Studio (SSMS)**.
2. Ejecutar los scripts en orden cronológico (`módulo 3` -> `módulo 4` -> `módulo 5`).
3. Abrir el archivo `.pbix` en Power BI Desktop para interactuar con el modelo visual.
